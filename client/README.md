🛒 ShopEase — E-commerce Demo

A modern, responsive e-commerce demo site for a fictional online store, built with the MERN stack, Vite, and Stripe for payment processing.
🛠 Tech Stack

    MongoDB – Database for storing products and orders

    Express.js – Backend API and server routing

    React – Frontend with functional components and hooks

    Node.js – Backend runtime environment

    Vite – Blazing-fast development and build tool

    Bootstrap 5 – Layout and responsive design framework

    Stripe – Fully integrated payment processing

🔍 Pages

    Home – Featured products and promotional highlights

    Products – Browse a full catalog with images, prices, and quick views

    Product Details – View detailed product descriptions and specifications

    Cart – Add, update, and remove items from the shopping cart

    Checkout – Secure Stripe-powered checkout flow

    Order Confirmation – Purchase confirmation page

    Footer – Persistent footer with contact information and site links

💳 Payment Integration

This project uses Stripe Checkout to securely handle real or test payment transactions.
To enable payments:

    Create a Stripe account

    Obtain your public key and secret key

    Set up your .env file or environment variables as follows:

VITE_STRIPE_PUBLIC_KEY=your_public_key_here
STRIPE_SECRET_KEY=your_secret_key_here

    Stripe’s test mode is enabled by default for development.
